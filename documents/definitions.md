# Definitions

* Use case 
     * A is a description of how a person or system interacts with a solution to achieve
 specific goals. It outlines the steps or actions taken to accomplish a specific task or function.
 It is commonly used in software development to define the features to be added during the
 development process based on user interaction scenarios. Use cases help developers
 understand the functional requirements and align them with the user's expectations.

* Demonstrator
     * A demonstrator is a showcase implementation that demonstrates the abilities of NAIC.
 It requires three elements: (1) a connection to a community (academia, industry, or public
 sector), (2) the development of a use case of relevance for the community formulated as a
 ML/AI task, and (3) a ML/AI pipeline (software) to solve the task. Demonstrators are
 realized as Python notebooks with associated environments, made available as public
 repositories, interactive notebooks on Sigma2 resources, and PDF documents.
